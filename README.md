## Project Description
The **Frontend Web Application** is the user interface layer of the MedPortal Enterprise Cloud Architecture system. It provides a dashboard to manage appointments, doctors, patients, clinical records, and lab report uploads by successfully consuming the backend microservices deployed on Google Cloud Platform via the API Gateway and Global Load Balancer.
